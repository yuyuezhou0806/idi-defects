# IDI Defects

工程质量险潜在缺陷公开数据与静态检索演示。

本仓库提供 599 条结构化工程缺陷记录，可用于质量风险检索、缺陷分类浏览和工程检测参考。

[在线使用完整系统](http://1.15.170.85/idi/)

## 内容

- `defects.json`：公开的结构化缺陷数据
- `index.html`：无需后端即可打开的静态检索页面

数据记录包括缺陷类别、问题描述、参考标准和整改建议等字段。

## 快速使用

直接下载仓库并打开 `index.html`，或通过任意静态服务器运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 完整系统

线上版本在静态检索基础上增加了：

- 用户登录与权限管理
- 查询统计与安全日志
- 报告生成
- 与工程检测 Agent 的知识检索联动

为保护公司与用户数据，本仓库不包含用户数据库、访问日志、内部文档、服务器配置及部署凭证。
